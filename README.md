# А что, если…

Бесплатный мини-сервис: пять вопросов → три идеи полезных цифровых сервисов под свою работу, бизнес или личную задачу. Mobile-first, на русском языке.

## Как открыть проект

Нужен Node.js 22 или новее (среда проверена на Node.js 24) и npm.

1. Открой терминал в папке проекта.
2. Выполни `npm ci` — это установит зависимости.
3. Выполни `npm run dev`.
4. Открой адрес, который покажет терминал (обычно `http://localhost:3000`).

Для готовой production-версии: `npm run build`, затем `npm run start`.
Публикация: импортируй репозиторий в Vercel или на другой хостинг с поддержкой Node.js и Next.js. Статический хостинг вроде GitHub Pages не поддерживает серверный маршрут этого приложения.

## Где поставить свою ссылку VK

Единая настройка находится в **`lib/config.ts`**, константа **`VK_URL`**. Замени `https://vk.me/REPLACE_WITH_YOUR_PAGE` на ссылку личных сообщений своей страницы: например `https://vk.me/имя_страницы`.

Другой способ: создать `.env.local` и указать `NEXT_PUBLIC_VK_URL=https://vk.me/имя_страницы`. Перезапусти разработку; для production пересобери приложение. Обе кнопки контакта используют одну настройку. Пока ссылка не задана, кнопка явно сообщает, что контакт ещё не настроен, и не отправляет посетителя на несуществующую страницу.

## DEMO MODE уже работает

Без ключа приложение полностью работает: вопросы, генерация, три разных идеи, копирование, системное меню «Поделиться» (где оно поддерживается), повторная попытка и дневной лимит.

Demo — локальный алгоритм на сервере, а не настоящий AI. Он выбирает сценарий по нише, задаче и словам из свободного ответа; учитывает аудиторию и цель, включает детали ситуации. Результаты используют разные механики: решение текущей задачи, персональный маршрут, обратная связь. При тех же ответах подборка повторяется. Данные не отправляются внешнему AI в demo-режиме.

## Как подключить настоящий AI

1. Скопируй `.env.example` в `.env.local` (этот файл исключён из Git).
2. Укажи свой `AI_API_KEY` от OpenAI **только на сервере**, при публикации — в защищённых переменных хостинга.
3. При необходимости измени `AI_MODEL` (по умолчанию `gpt-4.1-mini`).
4. Перезапусти приложение. У провайдера должны быть доступ к модели и оплаченный API; сеть должна разрешать `api.openai.com`.

Ключ не используется в клиентском коде. Никогда не добавляй к его имени `NEXT_PUBLIC_`. Маршрут `app/api/ideas/route.ts` проверяет ввод, вызывает API с тайм-аутом и проверяет структуру трёх идей. Ошибки AI показываются пользователю без списания попытки. Реальный API не проверялся без ключа. Ответы отправляются провайдеру только в AI-режиме; не вводи в свободное поле чувствительные данные. Для публичного AI-запуска рекомендуются серверный лимит, ограничение расходов и правила обработки данных.

## Лимит и данные

Три успешные генерации в календарный день по времени устройства. Счётчик хранится в localStorage этого браузера; на следующий день обновляется. Регистрация не нужна. При недоступном хранилище сервис сообщает об этом и не генерирует результат. Ответы и подборка находятся только в памяти страницы, при перезагрузке исчезают; счётчик сохраняется. Можно скопировать результат перед закрытием.

Это MVP-лимит, его можно обойти очисткой хранилища, другим браузером или прямым запросом API; он не защищает платный API от злоупотреблений. Интерфейс `QuotaStore` в `lib/quota.ts` позволяет заменить localStorage на серверный механизм. Для платного публичного AI сначала добавь серверную идентификацию и ограничение запросов. Одновременные вкладки также не дают строгого атомарного лимита.

## Проверки

- `npm run typecheck` — TypeScript.
- `npm test` — персонализация, разные сценарии, валидация и лимит.
- `npm run build` — production-сборка.
- `npx playwright install chromium` — один раз установить браузер для тестов.
- Если Chromium уже установлен в среде: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` — скачивать браузер не нужно.
- `npm run test:e2e` — сценарий анкеты, копирование, повтор, лимит, ошибки, API и ширины 375 / 390 / 430 / 768 / 1440 px. Production-сборка нужна заранее. Тесты AI предполагают отсутствие ключа (DEMO MODE).

## Структура

`app/page.tsx` — экраны и анкета; `app/globals.css` — адаптивный дизайн; `app/api/ideas/route.ts` — серверная генерация; `lib/ideas.ts` — схема данных и demo; `lib/questions.ts` — вопросы; `lib/config.ts` — VK и лимит; `lib/quota.ts` — заменяемое хранилище лимита.

Стек: Next.js App Router, React, TypeScript, Zod; обычный CSS с переменными вместо Tailwind — для небольшого авторского дизайна он не требует дополнительных зависимостей. Шрифты системные, приложение не зависит от загрузки внешних шрифтов. Учитываются safe-area, клавиатурная навигация, уведомления для скринридера и уменьшение анимаций по настройке устройства.

## Публикация на Render

В корне проекта подготовлен `render.yaml` (Render Blueprint). Он создаёт **Node.js Web Service**, а не Static Site: сервер нужен для `/api/ideas`. Дизайн и работа приложения при этом не меняются.

### Через Blueprint

1. Войди на [Render](https://dashboard.render.com/) и подключи GitHub.
2. Выбери **New → Blueprint** и репозиторий `lena-ds-design/a-chto-esli`, ветку `main`.
3. Render прочитает `render.yaml`. Проверь тариф Free и создай сервис. Создание Blueprint запускает первоначальную публикацию; автоматические публикации последующих коммитов отключены.
4. Дождись статуса **Live**. Адрес будет показан в панели сервиса — открой его в браузере.

### Вручную через Web Service

Если используешь **New → Web Service**, укажи:

| Поле | Значение |
| --- | --- |
| Repository | `lena-ds-design/a-chto-esli` |
| Branch | `main` |
| Runtime | Node |
| Root Directory | оставить пустым |
| Build Command | `npm ci --include=dev --no-audit --no-fund && npm run build` |
| Start Command | `npm run start -- --port $PORT` |
| Health Check Path | `/` |
| Instance Type | Free для тестовой версии |
| Auto-Deploy | отключить |

В Environment добавь `NODE_VERSION=24.19.0`, `NODE_ENV=production`, `NEXT_TELEMETRY_DISABLED=1`. Порт задаёт Render через `PORT`; приложение слушает `0.0.0.0`. `--include=dev` нужен для TypeScript во время сборки, даже когда установлен `NODE_ENV=production`.

### VK и AI на Render

- Для первого тестового запуска **не добавляй `AI_API_KEY`**: DEMO MODE работает без внешних ключей и платных запросов.
- Чтобы включить контакт, добавь `NEXT_PUBLIC_VK_URL` со своей ссылкой `https://vk.me/имя_страницы` в Environment и выбери **Save, rebuild, and deploy**. Эта переменная встраивается при сборке; одного перезапуска недостаточно.
- Настоящий AI при необходимости включается серверной переменной `AI_API_KEY` и необязательной `AI_MODEL`. Секрет вводится только в Render Environment, не в `render.yaml` или Git. Для публичного платного AI сначала потребуется серверная защита лимита, описанная выше.

### Проверка после публикации

Открой выданный Render HTTPS-адрес, пройди анкету и получи три идеи. Проверь копирование, повтор и ограничение после трёх успешных генераций. Без своей VK-ссылки кнопка контакта объясняет, что она ещё не настроена. На бесплатном тарифе сервис может засыпать при отсутствии запросов; первый заход после простоя занимает больше времени. Возможности бесплатного тарифа и доступность региона проверяй в панели Render при создании.

Production-сборка и запуск с отдельным `PORT` проверены локально. Публикация в аккаунте Render из этой среды не выполнялась; `render.yaml` не создаёт сервис сам по себе. При ошибке смотри Build/Deploy Logs в панели Render.
